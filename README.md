# Dollie’s Links

The custom cursor art is by [Mii](https://ko-fi.com/nekomimiyu/shop), used under the creator's free personal-use terms. It is included only for use as part of this personal website and must not be redistributed separately.

Ready-to-upload static website for GitHub Pages.

## Upload

1. Open your `dollie-links` repository on GitHub.
2. Choose **Add file → Upload files**.
3. Upload the **contents** of this folder, preserving the `assets` and `.github/workflows` folders.
4. Commit the files to `main`.
5. Open **Actions** and allow the “Deploy Dollie’s Links” workflow to finish.

The page includes an 18+ entrance gate, animated Dollie graphics, responsive link cards and a visitor-controlled music player. The song starts after the age-confirmation click when the browser permits it. The player can be hidden and reopened using the small music-note button.

The link buttons and music controls use a unified pink pixel-art icon system. Desktop visitors receive a custom pink pixel arrow cursor that changes into a glossy pixel heart over clickable elements.

`pixel-bunny.png` and `pixel-kitty.png` are included as unused transparent mascot assets for future experiments.
